Variáveis {{VAR}}

O {{VAR}} é substituído logo antes de um comando rodar. Funciona em comandos nativos, no diretório de trabalho, na URL / headers / body de HTTP, na resposta de uma auto-resposta e nos valores das condições de execução. Em código Python/Node ele não é substituído — leia as variáveis de ambiente.

Os nomes aceitam letras, dígitos, _ e . (o ponto alcança um campo de uma entrada de coleção: {{cliente.email}}); o prefixo $ é uma variável dinâmica ({{$uuid}}). Digitar {{ num editor sugere as variáveis disponíveis.

Precedência

Global  <  Pasta/Projeto  <  Dinâmica (HTTP)  <  Parâmetros

A da direita sobrescreve a da esquerda. Variável ausente vira string vazia (com aviso no log) — o Kai nunca trava por isso.

Texto condicional

Um bloco pode escolher qual texto sobrevive, antes de as variáveis serem substituídas:

docker compose up {% if {{BUILD}} == "true" %}--build{% else %}--no-build{% endif %} {{service}}
  • {% if A op B %} … {% else %} opcional … {% endif %}; os blocos podem ser aninhados.
  • Operadores: ==, !=, >, <, >=, <=. Com números dos dois lados a comparação é numérica ({% if {{PORT}} > 1000 %}); os operadores de ordem exigem números, senão a condição é falsa.
  • Os operandos são {{VAR}}, texto entre aspas ou um número. Sem operador a condição é verdadeira quando o valor não é vazio, nem false, nem 0: {% if {{VERBOSE}} %}-v{% endif %}.
  • kai --dry-run mostra o texto depois de os blocos serem resolvidos.
