Coleções & Parâmetros

Parâmetros pedem valores antes de executar (texto, select, bool, arquivo). Um select pode puxar opções de uma Coleção.

Exemplo

Comando echo {{cliente.value}} com um parâmetro cliente do tipo select ligado à coleção Clientes (campo exibido: value). Ao rodar, você escolhe o cliente e o Kai injeta {{cliente.value}}, {{cliente.key}} etc.

Importar dados

Coleções aceitam import de CSV/JSON; entradas vazias são ignoradas.
