Loja

A Loja encontra e instala coisas feitas para o Kai: comandos, pastas, pipelines, projetos, ambientes e perfis de execução. Ela não é um servidor nosso: você adiciona provedores (um repositório Git, um arquivo de catálogo ou uma API) em Configurações → Loja. Sem nenhum, não há entrada da Loja e o Kai nunca contata nada.

Instalar

Exibir → Loja (o painel com o carrinho) lista os pacotes de um provedor. Instalar baixa os arquivos, confere cada hash e mostra uma prévia antes de gravar qualquer coisa: o código de cada comando, os programas que ele exige e as URLs que chama.

  • Hooks de um pacote nunca são instalados.
  • Agendamentos e executar ao iniciar o Kai são perguntados por comando e começam desligados.
  • Segredos viram variáveis vazias para você preencher.
Pacotes são código. Leia a prévia e adicione só provedores em que você confia.

Atualizar e desinstalar

Atualizações são buscadas só com a Loja aberta ou ao clicar em Atualizar. Se você editou um pacote instalado, Instalar como cópia mantém a sua versão. Desinstalar remove só o que a instalação criou.

Terminal

kai store list
kai store search deploy
kai store install acme/ship-to-staging

Publicar o seu é só colocar arquivos num repositório Git; veja docs/store.md.
