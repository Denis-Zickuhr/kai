Dynamic variables / faker

Tokens with $ are resolved at execution time:

{{$uuid}}UUID v4
{{$timestamp}}epoch in seconds
{{$timestampMs}}epoch in milliseconds
{{$isoTimestamp}}ISO-8601 date/time (UTC)
{{$randomInt}}integer [0, 100000)
{{$randomInt.N}}integer [0, N)
{ "id": "{{$uuid}}", "ts": {{$timestamp}} }
