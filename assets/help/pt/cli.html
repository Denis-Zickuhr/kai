CLI — controle o Kai pelo terminal

Com o Kai aberto, use o binário como cliente (vibe CopyQ):

kai run "Deploy"executa um comando pelo nome
kai listlista os comandos
kai env listlista os environments
kai env use Prodativa um environment
kai pslista os processos em execução (nome, PID, status)
kai attach <pid|nome>conecta a saída a um processo
kai kill <pid|nome>encerra um processo
kai showtraz a janela à frente

Ótimo para scripts, Makefiles e CI. Abrir o Kai duas vezes só reexibe a janela (instância única).
