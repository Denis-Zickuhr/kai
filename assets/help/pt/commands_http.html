Comandos HTTP

Um comando HTTP faz uma requisição e mostra a resposta formatada. No editor ele tem quatro páginas: Geral (método, URL, corpo), Requisição (headers, parâmetros de query, autenticação), Conexão e Resposta (extratores, asserções, salvar em arquivo).

Método e URL

GET, POST, PUT, PATCH, DELETE, QUERY, HEAD e OPTIONS estão na lista; o campo é editável, então qualquer outro verbo (PROPFIND…) pode ser digitado. A URL aceita variáveis: {{BASE_URL}}/users.

Headers, query e autenticação

Headers e parâmetros de query são tabelas; cada linha tem uma caixa para desligá-la sem apagar. A autenticação é uma escolha: Basic, Token Bearer, Chave de API (header ou query), Nenhuma ou Herdar das pastas. Use uma variável marcada como Secreta ({{API_TOKEN}}) em vez de digitar o token. Um header Authorization escrito à mão sempre vence.

Compartilhe headers com uma pasta

A aba HTTP de uma pasta guarda headers, autenticação e opções de conexão que todo comando HTTP dela e das subpastas herda. Um header de mesmo nome definido mais perto do comando substitui o herdado; na página Requisição do comando os herdados aparecem com a pasta de origem — desmarque um para desligá-lo naquele comando.

Conexão

Redirecionamentos (seguidos por padrão; a cadeia aparece na aba Requisição), verificação de TLS, proxy (system lê HTTPS_PROXY/HTTP_PROXY/NO_PROXY, ou none, ou uma URL), tempo limite (desligado por padrão: Ative para limitar só esta requisição ou pasta; enquanto a requisição espera, a saída mostra o tempo decorrido e se há limite) e o jar de cookies. Sem nenhuma resposta (tempo esgotado, conexão recusada) a aba Requisição abre com o motivo. Os cookies ficam na memória enquanto o Kai está aberto e são compartilhados entre as requisições; Arquivo → Limpar cookies HTTP os apaga. Cada opção pode ficar em Herdar.

Resposta

O JSON é uma árvore recolhível (Copiar, Destacar); o XML é indentado; imagens, PDFs e outros conteúdos binários ganham uma aba Conteúdo com pré-visualização e o botão Salvar em arquivo…. A aba Requisição mostra o que foi enviado, os redirecionamentos e o tempo até o primeiro byte; Headers mostra os headers da resposta.

Extrair um valor para uma variável

Configure um extrator para pegar um campo do JSON de resposta numa variável dinâmica (ex.: data.token → AUTH_TOKEN), usada pelos próximos comandos: Authorization: Bearer {{AUTH_TOKEN}}.

Asserções

Verificações sobre a resposta, no mesmo formato das condições de execução: {{RESPONSE_STATUS}} igual a 201. Com alguma ligada, elas decidem o sucesso (então um 404 pode ser o esperado). Variáveis: RESPONSE_STATUS, RESPONSE_TIME_MS, RESPONSE_SIZE, RESPONSE_CONTENT_TYPE, RESPONSE_BODY, RESPONSE_HEADER_<NOME> e as variáveis extraídas. Elas continuam disponíveis para os próximos comandos e hooks.

Salvar a resposta em um arquivo

Na página Resposta, informe um caminho: respostas bem-sucedidas (2xx) são gravadas nele conforme chegam, em vez de ficarem na memória.

Parar e fluxos de eventos

O botão Parar cancela uma requisição em andamento. Uma resposta text/event-stream (Server-Sent Events) aparece conforme os eventos chegam e continua até o servidor fechar ou você apertar Parar; aumente o Tempo limite (ele conta o tempo sem dados) para fluxos lentos.

Edição rápida

O botão Edição rápida (barra lateral ou atalho) abre método, URL, corpo, query, headers e autenticação sem o editor completo. Comandos HTTP novos já vêm com Content-Type e Accept: application/json e corpo JSON; o Host é enviado automaticamente a partir da URL.

Copiar como cURL ou código

O botão Copiar como… copia a requisição como cURL, Python (requests) ou JavaScript (fetch), com as variáveis resolvidas. O caminho inverso: Importar cURL.

Exemplo

- name: "Criar usuário"
  type: "http"
  http_config:
    method: "POST"
    url: "{{BASE_URL}}/users"
    auth:
      type: "bearer"
      token: "{{API_TOKEN}}"
    body_type: "json"
    body: "{\"name\": \"{{NAME}}\"}"
    env_extractors:
      - json_path: "id"
        env_var: "USER_ID"
    assertions:
      - left: "{{RESPONSE_STATUS}}"
        op: "eq"
        right: "201"
