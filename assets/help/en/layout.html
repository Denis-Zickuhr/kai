Panels & layout

The Kai window is a board of panels that you can move, close and bring back. The default layout has the command list on the left and the Output on the right, half the window each, both with their tab strip showing. It is what you see until you change something; the old arrangement (list on top, Output below) is the Classic perspective.

The grid

Panels live in the cells of a grid of columns × rows (1 to 5 each; the default is 2 × 2). A cell with more than one panel shows them as tabs. A cell with no panel disappears and its neighbours take its place: with Fill vertically each column stacks only its filled cells top to bottom (a lone cell takes the whole column); with Fill horizontally the same happens with the rows, left to right; with Fit nothing is absorbed and you drag the handle at a cell's corner to make it take more columns or rows. Settings → Layout → Panel grid sets the columns, the rows and the mode, with a small preview. Making the grid smaller never loses a panel: the ones in the removed cells become tabs of the nearest cell.

Commandsthe tree, its search and action buttons — left
Outputthe tabs of what ran — right
Documentthe README / notes reader: a tab next to the Output, follows the selection — read it while a command runs — right
Processes, History, Notificationsthe screens that used to be modal windows — right
Variablesthe environments screen (packages of variables and dynamic variables), edited in place — right
AI chatonly exists once you add a provider — right

The View menu

View is the way back to everything: the panel list (a highlighted icon means it is on the window; clicking closes it or brings it back to the last place it was), Panel position (move, float, maximize, collapse, close), Maximize panel, Rearrange panels, Perspectives and Restore layout. Close every panel and the window offers a Restore layout button. Settings → Layout has it too.

Moving panels

  • View → Rearrange panels is on by default: every cell shows its tab strip (turn it off to hide it on cells with a single panel).
  • Drag a tab to another cell. While you drag, the whole grid shows as dashed cells — empty ones too — plus a Float pill that turns the panel into a floating window; dropping on an empty cell fills it, dropping between the tabs of a cell inserts it at that position. Split this group (panel menu) shows all the panels of a cell at once instead of tabs.
  • Drag a tab out of the window to make it a floating window.

Moving never recreates a panel: a running command, its tabs and the Output text survive any move. The tab menu (right click or ⋯) has the same moves without dragging.

Maximize, collapse, float

  • Maximize: double click the tab, the menu or Ctrl+Shift+M. The old focus mode is the Output maximized.
  • Collapse to the side (cells on the edge of the grid only): the cell becomes a thin strip of icons on that edge; click one and the panel opens beside the content, pushing it aside; drag the divider to resize it and the strip's icons already switch panels, so the opened cell shows no tabs; click the icon again to close it. The strip comes back open after a restart.
  • Float: the panel gets its own window with an always on top pin and a dock back button. Floating windows hide with Kai and only return with it — they never appear by themselves.

Perspectives

View → Perspectives: Runner (default), Classic (list on top, Output below), Compact (only commands), HTTP (commands + a wide Output on the right), Reading (the Document on top of the Output, next to the list), Triple (list | Output | Document), Quad (four panels in a 2 × 2 grid) and your own — Save current layout…. Kai never switches perspective by itself.

Runs side by side and pinned KIP

Drag a tab out of the Output bar onto a cell (or right click it → Open in a panel): that run gets its own live panel, so two logs are visible at once. Right click a KIP command → Pin as panel to make it a permanent mini-app of the window; until you run it, it shows a Run button — nothing runs on its own.

Keyboard

Alt+1 … Alt+9focus the Nth visible panel
F6 / Shift+F6next / previous panel
Ctrl+Shift+Mmaximize / restore the focused panel

All remappable in Settings → Shortcuts.

In a small window the board scrolls instead of squeezing the panels: each cell keeps a comfortable size and forms (Variables, Processes, History…) keep the width they need.
The layout is personal: it lives in layout.json in your config folder and is never exported or part of a project.
