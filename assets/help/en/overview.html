Kai overview

Kai is a native command runner (C++/Qt6) for developers: it runs Shell scripts and HTTP requests, chains automations (hooks), injects per-environment variables, all with a global shortcut and low resource usage.

Typical workflow

  1. Create folders and, inside them, commands (Shell or HTTP).
  2. Define variables in an Environment (a selectable package at the top).
  3. Run with a double-click; follow the output in the Terminal Drawer.
  4. Automate with hooks (pre/post) and reuse them via the CLI.
Tip: use search (Ctrl+F) to find commands by name.

See also: Shell Commands, HTTP Commands, Environments.
