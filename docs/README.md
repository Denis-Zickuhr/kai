## Manifesto

- [Full `kai.json` manifesto](manifesto/kai-json-manifesto.md) — a
  self-contained reference meant to feed an AI model (or a human) that
  needs to generate a `kai.json` for a project: every accepted key, every
  parameter type, hooks, execution conditions, collections, and generic
  detection for projects without one.
