Terminal targets & WSL

A Shell command can run through a terminal target — a template that wraps the command. Classic case: running on WSL from Kai on Windows.

Default WSL target (Settings → Terminal Targets)

wsl.exe -- bash -lic 'eval "$(echo "$1" | base64 -d)"' kai {{command_b64}}

Placeholders: {{command}} (with safe quote escaping) and {{command_b64}} — crash-proof base64 injection, used by the default target above.

-lic, not just -lc: a login shell alone doesn't read ~/.bashrc (a stock Ubuntu .bashrc exits early for non-interactive shells). Adding -i makes your aliases and functions actually load.

working_dir via WSL

Kai injects a cd inside the shell so the working directory applies within WSL (the Windows process's own CWD never crosses that boundary).
