Import from cURL

In the command editor, HTTP tab, click Import cURL and paste a curl command. Kai recognizes:

-X/--requestmethod
-H/--headerheaders
-d/--data*body (infers POST)
-u/--userbecomes an Authorization Basic header
curl -X POST https://api.x.com/login \
  -H 'Content-Type: application/json' \
  -d '{"user":"admin"}'
