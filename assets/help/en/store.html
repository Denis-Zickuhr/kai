Store

The Store finds and installs things made for Kai: commands, folders, pipelines, projects, environments and execution profiles. It is not a server of ours: you add providers (a Git repository, a catalog file or an API) in Settings → Store. With none, there is no Store entry and Kai never contacts anything.

Install

View → Store (the shopping-cart panel) lists the packages of a provider. Install downloads the files, checks every hash and shows a preview before anything is written: each command's code, the programs it needs and the URLs it calls.

  • Hooks in a package are never installed.
  • Schedules and run when Kai starts are asked per command and start off.
  • Secrets become empty variables for you to fill in.
Packages are code. Read the preview, and add only providers you trust.

Update and uninstall

Updates are looked up only when the Store is open or when you click Refresh. If you edited an installed package, Install as a copy keeps your version. Uninstall removes only what the install created.

Terminal

kai store list
kai store search deploy
kai store install acme/ship-to-staging

Publishing your own is just files in a Git repository; see docs/store.md.
