Alvos de terminal & WSL

Um comando Shell pode rodar através de um alvo de terminal — um template que envolve o comando. Caso clássico: rodar no WSL a partir do Kai no Windows.

Alvo WSL padrão (Configurações → Alvos de Terminal)

wsl.exe -- bash -lic 'eval "$(echo "$1" | base64 -d)"' kai {{command_b64}}

Placeholders: {{command}} (com escape seguro de aspas) e {{command_b64}} — injeção à prova de crash via base64, usada pelo alvo padrão acima.

-lic, não só -lc: um shell de login sozinho não lê o ~/.bashrc (o .bashrc padrão do Ubuntu sai cedo em shells não-interativos). Adicionar -i faz seus aliases e funções carregarem de verdade.

working_dir via WSL

O Kai injeta um cd dentro do shell para o diretório de trabalho valer no WSL (o CWD do processo Windows nunca atravessa essa fronteira).
