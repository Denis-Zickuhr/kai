Importar de cURL

No editor de comando, aba HTTP, clique Importar cURL e cole um comando curl. O Kai reconhece:

-X/--requestmétodo
-H/--headerheaders
-d/--data*body (infere POST)
-u/--userautenticação Basic
-F/--formformulário multipart (nome=@caminho envia um arquivo)
-I, -k, -x, -mHEAD, TLS inseguro, proxy, tempo limite

O caminho inverso é o botão Copiar como… da página HTTP.

curl -X POST https://api.x.com/login \
  -H 'Content-Type: application/json' \
  -d '{"user":"admin"}'
