Auto-respostas

Uma auto-resposta (auto-responder) responde um prompt na saída de um comando por você: quando a saída casa com um padrão, o Kai digita a resposta na entrada do comando. Use para ferramentas que perguntam Continuar? [s/N] e não têm uma flag para pular. Adicione na aba Auto-respostas do editor do comando.

Campos

Nomeobrigatório — uma resposta sem nome não é salva nem ativada
Habilitadadesligue uma sem apagá-la
Condição (regex)uma expressão regular testada contra a saída; os grupos capturados ficam disponíveis como \1, \2…
Respostao texto enviado, como se você tivesse digitado. Use \1 para reaproveitar um grupo capturado e {{VAR}} para interpolar variáveis
Limitar disparos / Máx. de disparosdispara no máximo N vezes por execução, para um prompt repetido não virar laço infinito

Exemplo

Condição: Digite o nome do banco \((\w+)\) para confirmar:
Resposta: \1

Toda resposta automática é ecoada na saída para você ver quem digitou.

Bom saber

  • Lê a saída ao vivo, então funciona com comandos em background também.
  • Não vale em comandos KIP (o programa já conversa com o Kai pelo protocolo).
  • No kai.yml é a lista responders.
