Environments (variable packages)

Global variables live in packages (Insomnia/Postman style). Only one is active at a time and feeds the Global scope.

Switch package

Use the selector at the top-right. Via the CLI: kai env use Prod.

Manage

The ⚙ button next to the selector opens the screen to create/duplicate/rename/delete packages and edit their variables.

Secret variables

Check the Secret column to mask the value in the interface (useful for tokens/passwords).
