AI assistant

Kai has an optional AI assistant: an editor assistant that writes or changes a command, a chat that can read — and, with your approval, change and run — things in Kai, and an MCP bridge for external agents. It does not exist until you add a provider: with none configured there are no AI buttons.

Nothing happens on its own. Every change or run is shown to you first, and your keys stay on your machine.

1. Add a provider

Settings → AI → Add. Pick Anthropic, OpenAI, Google Gemini (AI Studio key), a local server (Ollama, LM Studio — no key needed), OpenRouter or any OpenAI-compatible address. Type the model or press List models, then Test connection.

  • Supports tools — turn it off for a local model without tool calling: the chat only talks, the editor assistant still works.
  • Hide secret variables from this provider — values of secret variables are replaced by ***hidden*** in what the assistant reads.
  • The API key is kept in ai.json (mode 0600) and is never exported, synced, logged or put in a prompt. You can read it from an environment variable instead.

2. Editor assistant

In the command editor, the AI button next to Advanced mode opens a box: say what you want, press Generate and see a diff (+ added, - removed, ~ changed). Apply puts it back in the editor as a draft — nothing is saved until you press OK.

3. Chat

The ✨ button at the top right opens the chat. The picker shows a Local or Remote badge (remote: what the assistant reads is sent to that provider). You can switch provider mid-conversation — Kai warns that parts specific to the previous provider are lost.

  • Reads (commands, folders, environments, runs, logs…) run without asking.
  • Changes and runs show a card with a preview. Allow, Deny or Allow in this chat.
  • Deletes and stopping a process always ask for confirmation.
  • Every change has an Undo button on its card.
  • Whatever comes from a tool — outputs, logs, variable values — is treated as data, never as instructions.

Conversations are saved (and can be deleted one by one, or all at once in Settings → AI). They are never exported.

4. External agents (MCP)

Settings → AI → Allow external agents, then Copy client config and paste it in the agent (Claude Desktop, an IDE…). The agent starts kai mcp, which talks to the running Kai. Every change or run opens a card in an External agent window for you to allow or deny; secrets are hidden from them by default.

Details and the safety rules are in the repository: docs/ai.md. To try it with no key, run sample/ai/fake-provider.py.
