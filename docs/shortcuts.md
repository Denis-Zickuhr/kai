# Keyboard shortcuts

Everything below can be changed (or removed) in **Settings → Shortcuts**, which has a search box and *Restore Defaults*. A key can have several bindings.

## Default shortcuts

|   |   |
|---|---|
| `Ctrl+Shift+B` | Show / hide Kai — **global**, works even when another app is focused |
| `Ctrl+F` | Show or hide the search bar |
| `Ctrl+N` / `Ctrl+Shift+N` | New command / new folder |
| `F2` | Edit the selected item |
| `Delete` | Delete the selected item (asks first) |
| `→` / `←` | Next / previous folder tab |
| `Ins` | Open the context menu of the selected item |
| `Ctrl+'` | Focus the Output's input field (again: back to the tree) |
| `Ctrl+E` | Switch an open editor between Simple and Advanced (JSON) |
| `Esc` | Hide the window (only while Kai itself is focused) |
| `Ctrl+Q` | Quit Kai for real (the window's X only hides it) |
| Double-click / Enter | Run the command |

## Actions without a default key

Assign these yourself if you use them: **Run selected**, **Stop selected**, **Force stop selected**, **Reset selected**, **New collection**, **Edit current folder**, **Edit body (quick)**, **Expand / collapse selected**, **Expand / collapse all**, **Hide / show selected**, **Show / hide hidden items** and **Show only running commands**.

> **Tip:** The tree shortcuts (F2, Delete, arrows, Ins) only fire when the command tree has focus, so they never interfere with typing elsewhere.
