Comandos Shell

Um comando Shell roda uma linha (ou script) no seu shell.

Como criar

Menu Item → Novo comando, aba Shell. Preencha o comando e, opcionalmente, o diretório de trabalho.

npm run dev

Variáveis

Use {{VAR}} para interpolar variáveis do ambiente ativo:

echo "Subindo na porta {{PORT}} ({{NODE_ENV}})"

Background

Marque Executar em background para processos longos (ex.: um dev server). O Kai mantém o processo vivo e mostra o status; pare quando quiser.

Comandos interativos com read aceitam entrada direto no campo de entrada do painel de saída.

Terminal interativo (configurações avançadas)

Para apps de tela cheia que desenham via cursor — vim, htop, less, um Claude Code aninhado — ative Terminal interativo (TUI). A saída vira uma grade de terminal de verdade em vez de um log em texto puro, então redesenho, cores e teclado se comportam como um terminal real:

htop

Ignorar código de saída (configurações avançadas)

Alguns programas retornam um código de saída diferente de zero mesmo funcionando perfeitamente — o caso clássico é o explorer.exe chamado do WSL para abrir uma pasta no Windows. Ative Ignorar código de saída e o Kai sempre trata o comando como sucesso; um crash de processo de verdade (sinal/segfault) continua sendo reportado normalmente:

explorer.exe .

Ocultar o Kai ao executar (configurações avançadas)

Para um comando que abre outro app ou janela e o Kai só estorvaria — ex.: um editor de código:

code .

Alvos de terminal (WSL, containers, ...)

Escolha um alvo em Alvo de Terminal para rodar o comando através de um wrapper — veja Alvos de Terminal & WSL.
