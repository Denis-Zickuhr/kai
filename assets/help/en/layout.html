Panels & layout

The Kai window is a board of panels that you can move, close and bring back. The default layout has the command list on the left and the Output on the right, half the window each, both with their tab strip showing. It is what you see until you change something; the old arrangement (list on top, Output below) is the Classic perspective.

The four zones

Panels live in four zones: Left, Center, Right and Bottom. A zone with more than one panel shows them as tabs; an empty zone disappears.

Commandsthe tree, its search and action buttons — left
Outputthe tabs of what ran — right
Documentthe README / notes reader: read it while a command runs — right
Processes, History, Notificationsthe screens that used to be modal windows — right
Variablesthe dynamic variables — right
AI chatonly exists once you add a provider — right

The View menu

View is the way back to everything: the panel list (a highlighted icon means it is on the window; clicking closes it or brings it back to the last place it was), Panel position (move, float, maximize, collapse, close), Maximize panel, Rearrange panels, Perspectives and Restore layout. Close every panel and the window offers a Restore layout button. Settings → Layout has it too.

Moving panels

  • View → Rearrange panels is on by default: every zone shows its tab strip (turn it off to hide it on zones with a single panel).
  • Drag a tab to another zone. Four dashed regions always show where it can land, whatever the layout: left and right (full height), bottom and center; dropping between the tabs of a zone inserts it at that position.
  • Drag a tab out of the window to make it a floating window.

Moving never recreates a panel: a running command, its tabs and the Output text survive any move. The tab menu (right click or ⋯) has the same moves without dragging.

Maximize, collapse, float

  • Maximize: double click the tab, the menu or Ctrl+Shift+M. The old focus mode is the Output maximized.
  • Collapse to the side: the zone becomes a thin strip of icons; click one and the panel opens beside the content, pushing it aside; drag the divider to resize it and the strip's icons already switch panels, so the opened zone shows no tabs; click the icon again to close it.
  • Float: the panel gets its own window with an always on top pin and a dock back button. Floating windows hide with Kai and only return with it — they never appear by themselves.

Perspectives

View → Perspectives: Runner (default), Classic (list in the center, Output below), Compact (only commands), HTTP (commands + a wide Output on the right), Reading (the Document in the center) and your own — Save current layout…. Kai never switches perspective by itself.

Runs side by side and pinned KIP

Drag a tab out of the Output bar onto a zone (or right click it → Open in a panel): that run gets its own live panel, so two logs are visible at once. Right click a KIP command → Pin as panel to make it a permanent mini-app of the window; until you run it, it shows a Run button — nothing runs on its own.

Keyboard

Alt+1 … Alt+9focus the Nth visible panel
F6 / Shift+F6next / previous panel
Ctrl+Shift+Mmaximize / restore the focused panel

All remappable in Settings → Shortcuts.

The layout is personal: it lives in layout.json in your config folder and is never exported or part of a project.
