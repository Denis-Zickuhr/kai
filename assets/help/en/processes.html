Processes & PID (view/attach/kill)

When you run a command, the Output header shows the process PID (e.g. pid 12345) — useful for monitoring and controlling it from outside.

Via the CLI (with Kai open)

kai pslists the processes: nome | pid N | status
kai attach 12345attaches the output to the process (by PID)
kai attach "Dev Server"or by command name
kai kill 12345terminates the process (by PID or name)
The kill terminates the ENTIRE process group (terminate → timeout → kill), also killing any child processes the script spawned — it leaves no orphans.
