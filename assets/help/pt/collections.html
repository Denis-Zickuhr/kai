Coleções

Uma Coleção é a sua própria tabela de dados (clientes, servidores, ambientes — o que precisar) que um parâmetro select pode usar como lista de opções. Crie em Item → Nova Coleção; ela pertence a uma pasta/aba.

Schema e entradas

O editor tem três abas à esquerda, como o editor de comandos:

  • Geral — nome, ícone, pasta, ordem e um resumo dos campos; Schema… os edita (um é a chave, um o valor, mais quaisquer outros).
  • Dados — as entradas numa tabela. Dá para marcar favoritos, filtrar, importar um arquivo CSV ou JSON ou Colar registros da área de transferência: JSON (um array de objetos ou um objeto) ou linhas copiadas de uma planilha (separadas por tab) ou de CSV. Uma primeira linha que nomeia os campos (pelo nome ou rótulo) vira o cabeçalho; senão as colunas vão para os campos na ordem. O Kai mostra quantos registros achou e pergunta antes de adicionar. Entradas totalmente vazias são ignoradas.
  • Avançado — a coleção em JSON, editável. O texto volta para a coleção ao sair da aba ou salvar; JSON inválido mantém você na aba até corrigir.

Exemplo

Um comando echo {{cliente.value}} com um parâmetro cliente do tipo select ligado à coleção Clientes (campo exibido: value). Ao rodar, você escolhe o cliente e o Kai injeta {{cliente.value}} (o campo exibido) e {{cliente.key}} mais todos os outros campos da entrada.

Versionando junto do projeto

Coleções podem morar dentro do kai.yml de um projeto; o parâmetro referencia a coleção pelo nome. Ao exportar, as entradas ficam de fora a menos que você ative — elas podem ter dado de verdade.
