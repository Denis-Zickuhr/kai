# Kai Docs & Notes

A sandbox for the documentation viewer: open this folder's README, then try
the files next to it and the notes of the project.

- Use the funnel in **Documents** to show `.json`, `.yml` and `.xml` files.
- JSON, YAML and XML open with colors and a **fold arrow** in the gutter;
  the two buttons next to the pencil collapse / expand everything.
- **Ctrl+Shift+[** and **Ctrl+Shift+]** fold / unfold the block under the cursor.
- The **Notes** section lists the project's notes with their type (MD, JSON,
  YAML, XML).

| File | What to try |
| --- | --- |
| `config.json` | nested objects and arrays, collapse all / expand all |
| `services.yml` | indentation-based folding, lists glued to their key |
| `feed.xml` | elements, comments and CDATA |
