Collections & Parameters

Parameters ask for values before running (text, select, bool, file). A select can pull its options from a Collection.

Example

A command echo {{cliente.value}} with a cliente parameter of type select bound to the Clientes collection (displayed field: value). At run time you pick the client and Kai injects {{cliente.value}}, {{cliente.key}}, etc.

Import data

Collections accept CSV/JSON import; empty entries are ignored.
