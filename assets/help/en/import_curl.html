Import from cURL

In the command editor, HTTP tab, click Import cURL and paste a curl command. Kai recognizes:

-X/--requestmethod
-H/--headerheaders
-d/--data*body (infers POST)
-u/--userBasic authentication
-F/--formmultipart form (name=@path uploads a file)
-I, -k, -x, -mHEAD, insecure TLS, proxy, timeout

The opposite direction is the Copy as… button of the HTTP page.

curl -X POST https://api.x.com/login \
  -H 'Content-Type: application/json' \
  -d '{"user":"admin"}'
