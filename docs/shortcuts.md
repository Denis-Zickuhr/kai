# Keyboard shortcuts

| Shortcut | Action |
|--------|------|
| `Ctrl+Shift+B` | Show/hide Kai (global, configurable) |
| `Ctrl+F` | Show/focus the search bar |
| `Ctrl+N` | New command |
| `Ctrl+Shift+N` | New folder |
| `F2` | Edit the selected item |
| `Delete` | Delete the selected item |
| `Ctrl+Q` | Quit Kai |
| `→` / `←` | Navigate between tabs (configurable) |
| Double-click | Runs the command |

All of these are **remappable** in **Settings**. Edit/Delete only fire
when the command tree has focus (they never interfere with typing
elsewhere).
