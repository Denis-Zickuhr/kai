CLI — control Kai from the terminal

With Kai open, use the binary as a client (CopyQ style):

kai run "Deploy"runs a command by name
kai listlists the commands
kai env listlists the environments
kai env use Prodactivates an environment
kai pslists the running processes (name, PID, status)
kai attach <pid|nome>attaches the output to a process
kai kill <pid|nome>terminates a process
kai showbrings the window to the front

Great for scripts, Makefiles and CI. Opening Kai twice just re-displays the window (single instance).
