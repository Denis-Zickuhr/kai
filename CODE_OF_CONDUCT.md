# Code of Conduct

Be respectful. Assume good faith, keep feedback about the work and not the
person, and don't harass anyone.

Unacceptable behavior includes insults, personal attacks, discrimination,
and publishing other people's private information. The maintainer may remove
comments, lock threads or block people who do this.

Report problems to the maintainer through a private GitHub contact or the
address in the repository profile.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
