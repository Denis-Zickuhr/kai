Parâmetros

Parâmetros pedem valores num formulário antes de um comando rodar. Adicione na aba Parâmetros do editor do comando; cada um vira {{nome}} no comando (ou na URL, nos headers e no body de um comando HTTP; em código Python/Node ele chega como variável de ambiente).

Tipos

textuma linha de texto
textareatexto com várias linhas que cresce conforme você digita
numberum campo numérico
boolum interruptor (inserido como true/false)
selectuma opção de uma lista fixa (opcionalmente multi-seleção, unida por vírgulas) ou uma entrada de uma coleção
fileum seletor de arquivo ou pasta (veja abaixo)
jsonum editor de trecho com realce de sintaxe, útil para bodies
dateum seletor de data para data, hora ou as duas, opcionalmente um intervalo

Opções comuns

  • Rótulo e valor padrão. O Kai lembra os últimos valores usados e preenche de novo; as opções de um select são ordenadas pelo uso mais recente.
  • Obrigatório coloca um asterisco e bloqueia o OK até ser preenchido.
  • Opcional esconde o campo atrás de uma caixa (Informar <rótulo>?) para um formulário longo continuar curto; só vale quando marcada.
  • Grupo — dê o mesmo nome de grupo a vários parâmetros para dobrá-los numa seção.
  • Descrição aparece no --help da CLI (veja CLI).

Arquivo e pasta

O Modo de seleção escolhe arquivo, pasta ou ambos (perguntado ao executar). O seletor abre na última pasta que você usou em qualquer lugar do Kai. O Formato do caminho converte o que o sistema devolve: native, posix (/mnt/c/...) ou windows (C:\...) — útil quando um Kai do Windows roda comandos no WSL.

Data

O campo de data mostra data, hora ou data e hora. Com Intervalo, {{nome}} é o início e {{nome.end}} o fim. O Formato de colagem escolhe como o valor é escrito: ISO, BR (15/01/2024), US, hora 24h, Unix em segundos ou milissegundos, ou um modelo próprio (yyyy-MM-dd HH:mm).

Select ligado a uma coleção

Escolher uma entrada injeta o campo exibido como {{nome}} e cada campo da entrada como {{nome.campo}} — veja Coleções.

Na linha de comando os parâmetros obrigatórios são posicionais e os opcionais são --nome=valor — veja CLI.
