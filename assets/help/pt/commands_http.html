Comandos HTTP

Um comando HTTP faz uma requisição e mostra a resposta formatada (JSON com árvore navegável).

Campos

MétodoGET/POST/PUT/PATCH/DELETE
URLaceita variáveis: {{BASE_URL}}/users
Headerspares chave/valor (também interpolados)
BodyJSON (o botão Formatar JSON embeleza)

Exemplo

{
  "name": "Autenticar",
  "type": "http",
  "http_config": {
    "method": "POST",
    "url": "{{BASE_URL}}/auth/login",
    "headers": { "Content-Type": "application/json" },
    "body": "{\"user\":\"{{USER}}\",\"pass\":\"{{PASS}}\"}",
    "env_extractors": [ { "json_path": "token", "env_var": "AUTH_TOKEN" } ]
  }
}

Extrair um valor para uma variável

Configure um Env Extractor pra pegar um campo do JSON de resposta e guardar numa variável dinâmica (ex.: data.token → AUTH_TOKEN), usada pelos próximos comandos:

Authorization: Bearer {{AUTH_TOKEN}}

Importar de cURL

Botão Importar cURL: cole um comando curl e o Kai preenche método/url/headers/body. Veja Importar cURL.

Abas Resposta, Requisição e Headers

A aba Resposta mostra o JSON retornado como árvore colapsável, com botões Copiar e Destacar. A aba Requisição mostra exatamente o que foi enviado — método, URL, headers, body — útil depois que a chamada já rodou. Headers mostra os headers da resposta.
