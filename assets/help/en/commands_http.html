HTTP Commands

An HTTP command makes a request and shows the formatted response (JSON with a navigable tree).

Fields

MethodGET/POST/PUT/PATCH/DELETE
URLaccepts variables: {{BASE_URL}}/users
Headerskey/value pairs (also interpolated)
BodyJSON (the Format JSON button prettifies it)

Example

{
  "name": "Authenticate",
  "type": "http",
  "http_config": {
    "method": "POST",
    "url": "{{BASE_URL}}/auth/login",
    "headers": { "Content-Type": "application/json" },
    "body": "{\"user\":\"{{USER}}\",\"pass\":\"{{PASS}}\"}",
    "env_extractors": [ { "json_path": "token", "env_var": "AUTH_TOKEN" } ]
  }
}

Extract a value into a variable

Configure an Env Extractor to grab a field from the JSON response and store it in a dynamic variable (e.g. data.token → AUTH_TOKEN), used by the following commands:

Authorization: Bearer {{AUTH_TOKEN}}

Import from cURL

Import cURL button: paste a curl command and Kai fills in method/url/headers/body. See cURL Import.

Response, Request and Headers tabs

The Response tab shows the JSON reply as a collapsible tree, with Copy and Pop out buttons. The Request tab shows exactly what was sent — method, URL, headers, body — useful once the call has already run. Headers shows the response headers.
