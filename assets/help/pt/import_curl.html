Importar de cURL

No editor de comando, aba HTTP, clique Importar cURL e cole um comando curl. O Kai reconhece:

-X/--requestmétodo
-H/--headerheaders
-d/--data*body (infere POST)
-u/--uservira header Authorization Basic
curl -X POST https://api.x.com/login \
  -H 'Content-Type: application/json' \
  -d '{"user":"admin"}'
