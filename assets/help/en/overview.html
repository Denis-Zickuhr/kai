Kai overview

Kai is a native command runner for developers: it keeps the commands you run every day — shell, Python, Node, HTTP requests — one global shortcut away, injects variables per environment, streams the output live and never leaves orphaned processes behind.

Typical workflow

  1. Create folders (they become tabs) and, inside them, commands — see Folders, tree & search.
  2. Write the command: a shell line, Python or Node code or an HTTP request. Ask for values with parameters.
  3. Set variables in an environment (the selector at the top) and use them as {{VAR}}.
  4. Run with a double-click or Enter; follow the Output live.
  5. Automate: hooks, schedules, auto-replies, and the command line.

The main window

  • Top bar: menus File (import, export, run history, logs, hide, quit), Item (new folder / command / collection), Settings and Help; the environment selector sits on the right.
  • Tabs and tree: one tab per folder, with the commands and subfolders in a tree; the side bar next to it runs, stops, edits and creates things.
  • Output panel: the result of the selected command (bottom by default; it can sit left or right in Settings → Layout).
  • Status line: how many commands are running (click for the process list), whether the last run succeeded and the unread notifications.
Press Ctrl+F to search commands by name. The global shortcut shows or hides Kai from anywhere.
